How cost is calculated. DBUs from system.billing.usage × list price from system.billing.list_prices (USD). SQL Warehouse cost is split across users in proportion to the number of queries each ran that day (system.query.history); idle warehouse cost stays with the warehouse owner. Local currency uses the last available ECB reference rate on or before each month end (Frankfurter API).
Disclaimer. List-price cost excludes negotiated discounts and, for classic compute, the cloud provider's VM/storage charges. Converted figures will closely match but not exactly equal your cloud invoice.
